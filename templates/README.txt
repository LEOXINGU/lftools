===============================================================================
TopoGeo Demo
Geospatial Database Template for LFTools
===============================================================================

TopoGeo_Demo.gpkg is a simplified GeoPackage database template developed to
demonstrate the automation features available in the LFTools plugin.

This template contains the minimum database structure required to quickly
test the automated cadastral survey description (Memorial Descritivo)
generation tools and other related functionalities.

HOW TO USE
-------------------------------------------------------------------------------
1. Do not edit this file directly.

2. Use the corresponding LFTools tool to create a copy of this template in
   the desired location.

3. During the copy process, you may choose the Coordinate Reference System
   (CRS) for the new project.

4. Use the newly created GeoPackage to store and manage your own data.

IMPORTANT
-------------------------------------------------------------------------------
This file is a demonstration (Demo) version intended solely for use with
the LFTools plugin.

The complete TopoGeo database model, including a much more comprehensive
database structure, detailed documentation, additional templates, and full
automation workflows, is available as part of the GeoOne QGIS Automation
Course and its official learning materials.
